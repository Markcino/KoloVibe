# Django web client — restricted R1 shell

The user expanded R1 to include a Django server-rendered web client. It provides public video and creator reads and viewer account forms. Creator publishing and playback remain gated, so the web client is **not** a full R1 journey implementation.

Run local tests from the repository root with `.venv/bin/python scripts/run_local_web.py test tests`. The root `.env` supplies the unique web secret and loopback gateway URL; no credential is bundled in the client. The existing local profile keeps its browser-token-cookie test fixture for isolated development only.

Restricted staging uses a separate PostgreSQL `web` schema and `kolovibe_web_app` role, Django database sessions, a `__Host-kolovibe_session` browser cookie, and an encrypted credential row keyed by the browser session. The encryption key and Django signing key are separate owner-only secret files. The web service runs on the VM2 Swarm worker, calls `https://gateway:8000` over the private service overlay with verified TLS, and connects to `kolovibe-postgres` over the private data overlay with `verify-full` TLS. VM1's HAProxy TCP bridge carries the web TLS stream through a separate Unix socket to host Nginx, which verifies the pinned web certificate. No application port is published. Production still refuses to start. Staging requires database provisioning, image publication, a guarded bridge/Nginx change, and observed acceptance before it can be called ready.

Discovery follows gateway cursor pages and rejects malformed records before rendering. Staging checks identity on every protected request, enforces 30-minute idle and 8-hour absolute limits, serializes refresh rotation, and clears the browser session while reporting unconfirmed server revocation on logout failure. Expired rows need a scheduled purge using `python manage.py clearsessions` and a bounded deletion of expired `web_credential` rows. For reproducible tests with isolated PostgreSQL, a real gateway and private test-mail capture, follow the [local acceptance procedure](../../docs/engineering/API_Test_Deployment_Roadmap.md#reproducible-isolated-local-acceptance).
