# Mobile design baseline

Source of truth: [approved KoloVibe mobile UI](https://www.figma.com/design/ANaV0jnwjZ0LEcByTc98HP/KoloVibe?node-id=0-1), 108 screen/state entries M-001 through M-108.

The application implements native presentation recipes for all 108 designs, backed by shared Flutter widgets and a development-only preview gallery. Live service and media integrations remain pending. Treat the approved Figma layouts as acceptance targets; do not fabricate engagement, creators or video playback. All new UI must follow the project navy/red/gold/lavender palette, mobile safe areas and accessibility requirements.

- Home: multi-service hub, not a TikTok feed.
- Explore: category and original-content discovery.
- Videos: edge-to-edge portrait video experience, Following / For You.
- Create: authorized creator onboarding and publishing.
- Profile: account, Creator Studio, non-cash Lone Stars.

The product is mobile-first. Desktop/web implementation remains deferred.

Implementation details: [mobile UI milestone](mobile-ui-implementation.md), [coverage register](mobile-design-coverage.md), and [asset provenance](mobile-asset-manifest.json).
